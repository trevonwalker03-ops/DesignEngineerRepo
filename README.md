# Northline

Production board for Field office, a small studio. The main screen lists client work across Brief, In progress, Review, and Shipped.

The search field above the board filters by project name, client, or owner as you type. It reads the current list and does not change it. Jobs live in `lib/projects.ts`.

## Run

```bash
npm install
npm run dev
```

The board is served at [http://localhost:43127](http://localhost:43127).
